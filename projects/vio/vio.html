Visual Inertial Odometry (VIO)

Project Overview

In this project, I implemented both classical and deep learning-based Visual-Inertial Odometry (VIO) methods to estimate 6-DoF camera motion. In Phase 1, I worked with the EuRoC dataset—structured as time series data—to implement key components of the MSCKF algorithm, including IMU propagation, state augmentation, and measurement updates for fusing vision and inertial signals. In Phase 2, I generated synthetic sensor data in Blender and trained neural networks to predict relative pose using vision only, IMU only, and a combination of both. I evaluated all approaches using RMSE ATE and trajectory plots, comparing predictions with ground truth. This project deepened my understanding of sensor fusion, time-dependent data processing, and motion estimation in dynamic environments.
